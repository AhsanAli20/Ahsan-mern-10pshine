This application is designed to provide a seamless and secure note-taking experience with the following key functionalities:

Public Landing Page: A user-friendly, public homepage accessible to all visitors, providing an overview of the application and its core features before login.

Secure Authentication:

User Registration & Login: Robust system for new user sign-up and secure login.

Forgot Password: Functionality to securely reset a forgotten password.

Complete Note Management (CRUD): Logged-in users have full control over their notes:

Create: Easily add new notes with a title and description.

Read: View a list of all personal notes.

Update: Edit existing notes to modify content.

Delete: Permanently remove unwanted notes.

User Profile:

View Profile: Check and review personal account information.

Frontend	React.js	Used for building a dynamic and responsive Single Page Application (SPA).
Backend	Node.js & Express.js	The server-side environment and framework for handling API requests.
Database	MongoDB	A NoSQL database for flexible and scalable data storage (managed via Mongoose).
Authentication	JWT (JSON Web Tokens)	Used for secure, stateless user authentication.
Styling	Tailwind CSS	For a modern and responsive user interface.

Edit Profile: Update user details (e.g., name, email, password).
